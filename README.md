# Beetsol widget test page

A customer's page with Beetsol's widget on it, on a site of its own (as a customer's site is), for the widget's tests:
the release test's P17-2 and PR #18's widget sign-in.

Open https://shree-beetsol.github.io/beetsol-widget-test/?token=TOKEN, with the workspace's token from Settings > Embed,
after setting Settings > Embed's domain to `shree-beetsol.github.io`. The page holds no token. `&app=https://...` picks
another Beetsol address on beetsol.com (the default is https://app.beetsol.com).
